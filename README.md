LLM plugin for the OpenAI Decisions API

## Installation

Install this plugin in the same environment as [LLM](https://llm.datasette.io/).
```bash
llm install llm-openai-decisions
```

## Development

To set up this plugin locally, first checkout the code. Then run the tests with `uv`:
```bash
cd llm-openai-decisions
uv run pytest
```
To run LLM with your in-development plugin:
```bash
uv run llm --help
```
